## Decisions and deviations recorded

- Account Private: the first deploy failed with
  `ReadWriteTransfer is not a valid sharing model for Case when Account sharing model is Private` and
  `ReadWrite is not a valid sharing model for Opportunity when Account sharing model is Private`,
  so Opportunity and Case are Private/Private. Contact is ControlledByParent/ControlledByParent as listed in
  Decided (the deploy did not demand it; Contact ReadWrite with a Private Account would expose customer contacts).
  EntityDefinition reports Contact as Private (effective value); the retrieved Contact.object shows
  `<sharingModel>ControlledByParent</sharingModel>` and `<externalSharingModel>ControlledByParent</externalSharingModel>`.
- Skill conflict, handoff wins: platform-custom-object-generate defaults sharingModel to ReadWrite; Private per handoff.
  platform-custom-field-generate says numeric formulas use BlankAsZero; Margin__c uses BlankAsBlank so an empty
  Price__c or Carrier_Cost__c yields an empty margin (decided: empty when Price__c is 0 or empty).
  Delivery_Access_Code_Hash__c has no inlineHelpText (decided: no help text revealing purpose).
- API 67: DML and SOQL default to user mode, and the running admin has no FLS on the new fields
  (first run: `System.DmlException: Operation failed due to fields being inaccessible on Sobject Account`).
  Field permissions belong to T3, so ShipmentSchemaTest uses `AccessLevel.SYSTEM_MODE` / `WITH SYSTEM_MODE`
  for test-only DML and SOQL, with a `SECURITY-JUSTIFICATION` comment (approver placeholder:
  task-reviewer T1; the main session should confirm the approver).
- AC-F.6 field history is proven by Tooling, not Apex: Apex only sees FieldDefinition rows of fields the running
  user has FLS on (anonymous probe returned only `Name` for `QualifiedApiName IN ('Status__c','Estimated_Delivery__c','Name')`;
  the Apex test returned `Actual: {}`). The Apex assertion is kept for the sharing models, which Apex can see.
- Assumptions (not in the design): lengths Customer_Reference 50, postal codes 10, cities 80, recipient name 120,
  Package_Description/Last_Location 255, Proof_Id 100, addresses and instructions LongText 1000, Internal_Notes 5000;
  Weight_Kg Number(8,2); currencies (16,2); Reschedule_Count__c Number(2,0) default 0.
- No Shipment__c records exist in the org (`SELECT COUNT() FROM Shipment__c` = 0), per A6.
