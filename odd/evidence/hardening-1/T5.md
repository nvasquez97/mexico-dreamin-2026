## H5 (platform rule, recorded as decided)

Salesforce shows a field-history entry only to users who can read the field
(Field History Tracking documentation). Field history is not written inside an
Apex test and `Shipment__History` refuses DML, so no test without org data can
create a history row. The proof of G9 rests on:

1. `anaCannotAccessTheDeliveryInstructionsByDescribe` (new, no org data):
   Delivery_Instructions__c is not accessible to Ana by describe.
2. `anaCannotReadTheRecipientOwnedFieldsOfHerOwnShipment` (existing): the
   user-mode read of the four recipient-owned fields is refused.
3. `scripts/checks/customer-access-check.sh`: no FLS on the four fields.
4. The last green run of the SeeAllData history test in the gate @ 56bac29.
